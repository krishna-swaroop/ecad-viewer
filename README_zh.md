<p>

本仓库是 [Huaqiu-Electronics/ecad-viewer](https://github.com/Huaqiu-Electronics/ecad-viewer)
的分支，作为 [KiCAD-Prism](https://github.com/krishna-swaroop/KiCAD-Prism) 的
KiCad 文件查看器维护，已与上游有较大差异。上游 ecad-viewer 基于
[KiCanvas](https://github.com/theacodes/kicanvas)。

本分支的文档只维护英文版，请参阅 [README.md](README.md) 和 [docs/](docs/)。

上游项目的中文说明见
[Huaqiu-Electronics/ecad-viewer 的 README_zh.md](https://github.com/Huaqiu-Electronics/ecad-viewer/blob/main/README_zh.md)。
